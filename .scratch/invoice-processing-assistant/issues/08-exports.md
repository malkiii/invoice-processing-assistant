# 08 — Exports (CSV, XLSX, JSON) and downloads drawer

Status: ready-for-agent
Blocked by: 06

## What
See spec "Export".

## Scope
- `server/domain/export` turns merged values into:
  - JSON (nested)
  - XLSX (sheets for Invoices and Line items)
  - CSV in one of two layouts: one row per line item (default), or a zip of `invoices.csv` + `line_items.csv` linked by `invoice_id`
- Scope selection: a single Invoice, a selection, a Batch, or the current filter. A "Reviewed only" toggle.
- Large Exports are generated by a worker job and stored in object storage. A downloads history drawer in the `/app` layout.

## Acceptance
- Unit tests for flattening, covering Invoices without line items, nested objects and custom Template Fields.
